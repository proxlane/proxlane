An exhausted chain now summarises itself by what the target said rather than by which provider happened to run last. If any hop got a verdict from the target (class `blocked` or `target`), that verdict is the response's `X-Outcome`, `X-Provider-Used`, status and body; only when no hop reached the target does the last hop's outcome stand. A caller's chain of two spent wallets, a hard block and a rejected key used to report the rejected key, and swapping the last two providers made the same four facts report the block. `X-Chain` still lists every hop.
