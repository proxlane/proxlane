A one-click deploy. The homepage's first call to action is now a thing that runs rather than a page
that explains: a pinned image on the reader's own account, with the gateway key generated for them
and one provider key asked for. The blueprint lives in the repo as `render.yaml`, so it can be read
before it is clicked, and its image tag is written by the release rather than by hand.
